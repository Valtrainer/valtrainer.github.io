Code signing policy

Windows checks the digital signature of programs you download. Here is how ValTrainer's releases are signed, who can approve a signed release, and what the program does on your network.

Signing

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

  • What is signed: the Windows installer (ValTrainer-…-Setup.exe) and the program (ValTrainer.exe, also inside the portable zip) attached to the official releases on GitHub.
  • Built from public source: every signed file is built by the project's GitHub Actions release workflow from a tagged commit of the public source code. Nothing built on a personal PC is signed.
  • Approved by hand: each signing request is approved by a project approver (below) before the release is published.
  • Checking a download: compare its SHA-256 hash with SHA256SUMS.txt from the same release. If a file claiming to be ValTrainer is signed by anyone else, don't run it and report it.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user

The only network feature in ValTrainer is the update check, and from version 1.4.1 it is off until you allow it:

  • You're asked first: on the first start, ValTrainer asks “Check GitHub for new versions?”. Until you choose Enable updates, it makes no network request at all. Choose Not now and it stays offline.
  • What it asks: with updates enabled, ValTrainer asks GitHub's API (api.github.com) for the project's latest release at startup and every 6 hours. If a newer version is out, it downloads that release's files from GitHub and checks them against the release's SHA-256 hashes.
  • What it sends: nothing about you. The request carries only what every web request carries: your IP address and a ValTrainer/<version> user agent. GitHub handles it under GitHub's privacy statement.
  • You stay in control: Check now in Settings → About checks once, when you click it, even with automatic checks off. Check for updates and Download updates automatically can be turned off at any time.
  • Your data stays on your PC: settings, stats and run recordings are stored in %APPDATA%\ValTrainer and are never uploaded. There is no account and no analytics, and nothing is ever sent to the developers. VALORANT's settings files are only read, on your PC.

Versions 1.3.0 to 1.4.0 checked for updates automatically unless you turned it off in Settings. This website has no cookies, analytics, trackers or ads; it is hosted on GitHub Pages, which keeps standard server logs under GitHub's privacy statement.
