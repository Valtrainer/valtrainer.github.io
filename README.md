# valtrainer.github.io

The website of **ValTrainer**, a free aim, movement and utility trainer that plays with your own VALORANT settings:
**<https://valtrainer.github.io/>**

- The app, its source code, releases and issues: <https://github.com/idoraz1/ValTrainer>
- This repository is the static site (plain HTML, CSS and JavaScript, no build step). Every push to `main` is published
  to GitHub Pages by `.github/workflows/pages.yml`.
- Preview locally: `py -m http.server 8000`, then open <http://127.0.0.1:8000/>.
- The download buttons ask GitHub for the app's latest release, so a new app release needs no change here.
